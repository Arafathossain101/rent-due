# rent_due
🏠 Rent Record
Rent Record is a lightweight, intuitive mobile application built with Flutter to simplify property management for landlords and property managers. Easily organize properties, track tenants, and manage monthly rental payments—all in one place.

 Features
 Property & Room Management: Group units by property and easily navigate between individual tenant records.

Tenant Tracking: Store tenant details, rent amounts, and optional identification documents (images or PDFs) directly within the app.

Rent & Utility Ledger: Generate, track, and log monthly utility bills and rental payments seamlessly.

Payment Logs & Summaries: Maintain a clean history of transaction updates and keep tenant accounts up to date.

Clean & Modern UI: Simple, responsive layout designed for quick access on mobile devices.

Built With

Framework: Flutter

Language: Dart

Architecture: Local State Management
